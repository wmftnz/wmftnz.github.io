# willthompson-portfolio

Personal portfolio site for Will Thompson. Software engineer and founder of All Ears Events, Christchurch NZ.

Open `index.html` over HTTP (any static host works, including GitHub Pages). All styling and behaviour is local apart from React, loaded from a CDN at runtime.

`Will Thompson CV 2026.pdf` is embedded from `assets/will-thompson-cv.pdf` and served by the Download CV button.
